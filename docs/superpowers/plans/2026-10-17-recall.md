# Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Recall, a native macOS app that reviews Anki decks WaniKani-style: type the answer, get instant right/wrong feedback, and report the result back to Anki.

**Architecture:** A Swift package with a `RecallCore` library (AnkiConnect client, card parsing, answer checking, romaji conversion, stages, queue building, review-session state machine; all unit-tested against an in-memory fake Anki) and a thin SwiftUI `Recall` executable (dashboard, review, summary screens). A shell script bundles the release binary into `build/Recall.app`.

**Tech Stack:** Swift 6.4 (Swift 6 language mode), SwiftUI + Observation, Swift Testing, Swift Package Manager, AnkiConnect HTTP API v6. Xcode 27 is installed; no third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-10-17-recall-design.md`

## Global Constraints

- Platform: macOS 15+ (`platforms: [.macOS(.v15)]`).
- AnkiConnect endpoint: `http://127.0.0.1:8765`, every request sends `"version": 6`.
- Anki's bundle identifier: `net.ankiweb.anki`.
- Japanese Vocab note type name: `Japanese Vocab`; fields `Word`, `Meaning`, `Reading`, `Notes`; card `ord` 0 = Meaning, 1 = Reading.
- Grading: correct (exact or near-miss) → ease 3 (Good); wrong → ease 1 (Again). Every answer is sent immediately.
- Stage thresholds (interval in days; negative = learning seconds): Apprentice < 7, Guru 7–29, Master 30–89, Enlightened 90–179, Burned ≥ 180.
- Missed cards are re-queued 3–6 cards later (random), or at the end if fewer remain.
- Near-miss allowed distance by normalized length n: n ≤ 3 → 0, n ≤ 5 → 1, n ≤ 7 → 2, else 2 + ⌊(n − 7) / 7⌋. Reading cards: no near-miss.
- No third-party packages. No app sandbox.
- Commit after every task. Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```swift
/// WaniKani-style SRS stage derived from Anki's review interval.
public enum Stage: Int, CaseIterable, Comparable, Sendable {
    case apprentice, guru, master, enlightened, burned

    /// `interval` is AnkiConnect's `cardsInfo` interval: days when positive,
    /// seconds of a learning step when negative, 0 for new cards.
    public init(interval: Int) {
        switch interval {
        case ..<7: self = .apprentice
        case 7..<30: self = .guru
        case 30..<90: self = .master
        case 90..<180: self = .enlightened
        default: self = .burned
        }
    }

    public var name: String {
        switch self {
        case .apprentice: "Apprentice"
        case .guru: "Guru"
        case .master: "Master"
        case .enlightened: "Enlightened"
        case .burned: "Burned"
        }
    }

    public static func < (lhs: Stage, rhs: Stage) -> Bool { lhs.rawValue < rhs.rawValue }
}
```

```swift
import Foundation

public enum AnkiError: Error, Equatable, Sendable {
    /// Nothing answered on the AnkiConnect port: Anki is closed or the add-on is missing.
    case notRunning
    /// AnkiConnect answered with a non-null `error`.
    case api(String)
    case badResponse
}

/// The parts of AnkiConnect's `cardsInfo` that Recall uses.
public struct CardInfo: Sendable, Equatable {
    public let cardId: Int
    public let noteId: Int
    public let modelName: String
    /// Index of the card's template within the note type.
    public let ord: Int
    /// 0 new, 1 learning, 2 review, 3 relearning.
    public let type: Int
    /// Days when positive; seconds of a learning step when negative.
    public let interval: Int
    /// For new cards, the new-card position.
    public let due: Int
    /// Field names in note-type order.
    public let fieldNames: [String]
    /// Raw field HTML by field name.
    public let fields: [String: String]

    public init(cardId: Int, noteId: Int, modelName: String, ord: Int, type: Int, interval: Int, due: Int,
                fieldNames: [String], fields: [String: String]) {
        self.cardId = cardId
        self.noteId = noteId
        self.modelName = modelName
        self.ord = ord
        self.type = type
        self.interval = interval
        self.due = due
        self.fieldNames = fieldNames
        self.fields = fields
    }
}

extension CardInfo: Decodable {
    private enum CodingKeys: String, CodingKey {
        case cardId, note, modelName, ord, type, interval, due, fields
    }

    private struct Field: Decodable {
        let value: String
        let order: Int
    }

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        let raw = try c.decode([String: Field].self, forKey: .fields)
        self.init(
            cardId: try c.decode(Int.self, forKey: .cardId),
            noteId: try c.decode(Int.self, forKey: .note),
            modelName: try c.decode(String.self, forKey: .modelName),
            ord: try c.decode(Int.self, forKey: .ord),
            type: try c.decode(Int.self, forKey: .type),
            interval: try c.decode(Int.self, forKey: .interval),
            due: try c.decode(Int.self, forKey: .due),
            fieldNames: raw.sorted { $0.value.order < $1.value.order }.map(\.key),
            fields: raw.mapValues(\.value)
        )
    }
}

/// Everything Recall needs from Anki. `LiveAnki` talks to AnkiConnect; tests use a fake.
public protocol AnkiService: Sendable {
    func deckNames() async throws -> [String]
    func findCards(_ query: String) async throws -> [Int]
    func cardsInfo(_ cardIds: [Int]) async throws -> [CardInfo]
    func newCardsPerDay(deck: String) async throws -> Int
    func answerCard(_ cardId: Int, ease: Int) async throws
}

struct AnkiEnvelope<T: Decodable>: Decodable {
    let result: T?
    let error: String?
}

public struct LiveAnki: AnkiService {
    public static let defaultURL = URL(string: "http://127.0.0.1:8765")!

    let url: URL
    let session: URLSession

    public init(url: URL = LiveAnki.defaultURL, session: URLSession = .shared) {
        self.url = url
        self.session = session
    }

    public func deckNames() async throws -> [String] {
        try await call("deckNames")
    }

    public func findCards(_ query: String) async throws -> [Int] {
        try await call("findCards", ["query": query])
    }

    public func cardsInfo(_ cardIds: [Int]) async throws -> [CardInfo] {
        if cardIds.isEmpty { return [] }
        return try await call("cardsInfo", ["cards": cardIds])
    }

    public func newCardsPerDay(deck: String) async throws -> Int {
        struct Config: Decodable {
            struct New: Decodable { let perDay: Int }
            let new: New
        }
        let config: Config = try await call("getDeckConfig", ["deck": deck])
        return config.new.perDay
    }

    public func answerCard(_ cardId: Int, ease: Int) async throws {
        let accepted: [Bool] = try await call("answerCards", ["answers": [["cardId": cardId, "ease": ease]]])
        if accepted.first != true { throw AnkiError.api("Anki didn't accept the answer for card \(cardId)") }
    }

    func call<T: Decodable>(_ action: String, _ params: [String: Any] = [:]) async throws -> T {
        var request = URLRequest(url: url, timeoutInterval: 10)
        request.httpMethod = "POST"
        request.httpBody = try JSONSerialization.data(
            withJSONObject: ["action": action, "version": 6, "params": params])
        let data: Data
        do {
            (data, _) = try await session.data(for: request)
        } catch is URLError {
            throw AnkiError.notRunning
        }
        return try Self.decodeResult(data)
    }

    static func decodeResult<T: Decodable>(_ data: Data) throws -> T {
        let envelope: AnkiEnvelope<T>
        do {
            envelope = try JSONDecoder().decode(AnkiEnvelope<T>.self, from: data)
        } catch {
            throw AnkiError.badResponse
        }
        if let error = envelope.error { throw AnkiError.api(error) }
        guard let result = envelope.result else { throw AnkiError.badResponse }
        return result
    }
}
```

```swift
import Foundation

public enum QuestionKind: Sendable, Equatable {
    case meaning, reading, plain
}

/// A card ready to review: plain-text prompt and answer plus what kind of question it is.
public struct ReviewCard: Sendable, Equatable, Identifiable {
    public let id: Int
    public let prompt: String
    public let answer: String
    public let notes: String
    public let kind: QuestionKind
    public let stage: Stage

    public init(id: Int, prompt: String, answer: String, notes: String, kind: QuestionKind, stage: Stage) {
        self.id = id
        self.prompt = prompt
        self.answer = answer
        self.notes = notes
        self.kind = kind
        self.stage = stage
    }
}

public enum CardContent {
    public static let japaneseVocabModel = "Japanese Vocab"

    /// Builds the reviewable form of a card, or nil if it can't be type-checked.
    public static func reviewCard(from info: CardInfo) -> ReviewCard? {
        let prompt: String
        let answer: String
        let notes: String
        let kind: QuestionKind
        if info.modelName == japaneseVocabModel {
            // Template order in the note type: 0 = Meaning, 1 = Reading.
            kind = info.ord == 1 ? .reading : .meaning
            prompt = text(info, "Word")
            answer = text(info, kind == .reading ? "Reading" : "Meaning")
            notes = text(info, "Notes")
        } else {
            guard info.fieldNames.count >= 2 else { return nil }
            kind = .plain
            prompt = text(info, info.fieldNames[0])
            answer = text(info, info.fieldNames[1])
            notes = ""
        }
        guard !prompt.isEmpty, !answer.isEmpty else { return nil }
        return ReviewCard(id: info.cardId, prompt: prompt, answer: answer, notes: notes, kind: kind,
                          stage: Stage(interval: info.interval))
    }

    private static func text(_ info: CardInfo, _ field: String) -> String {
        plainText(fromHTML: info.fields[field] ?? "")
    }

    /// Anki field HTML → plain text: line breaks kept, tags, images and sounds dropped, entities decoded.
    public static func plainText(fromHTML html: String) -> String {
        var s = html
        s.replace(/\[sound:[^\]]*\]/, with: "")
        s.replace(/<br\s*\/?>/.ignoresCase(), with: "\n")
        s.replace(/<\/(div|p|li|h[1-6])>/.ignoresCase(), with: "\n")
        s.replace(/<[^>]*>/, with: "")
        s = decodeEntities(s)
        return s.split(separator: "\n")
            .map { $0.trimmingCharacters(in: .whitespaces) }
            .filter { !$0.isEmpty }
            .joined(separator: "\n")
    }

    static func decodeEntities(_ s: String) -> String {
        let named = ["amp": "&", "lt": "<", "gt": ">", "quot": "\"", "apos": "'", "nbsp": " "]
        return s.replacing(/&(#x[0-9a-fA-F]+|#[0-9]+|[a-zA-Z]+);/) { match in
            let body = String(match.1)
            if body.hasPrefix("#x"), let v = UInt32(body.dropFirst(2), radix: 16), let u = Unicode.Scalar(v) {
                return String(Character(u))
            }
            if body.hasPrefix("#"), let v = UInt32(body.dropFirst()), let u = Unicode.Scalar(v) {
                return String(Character(u))
            }
            return named[body] ?? String(match.0)
        }
    }
}
```

```swift
import Foundation

public enum Verdict: Sendable, Equatable {
    case exact
    /// Correct with a small typo; `expected` is the accepted answer it was close to.
    case nearMiss(expected: String)
    case wrong

    public var isCorrect: Bool { self != .wrong }
}

public enum AnswerChecker {
    public static func check(_ typed: String, against back: String, kind: QuestionKind) -> Verdict {
        let isReading = kind == .reading
        let given = normalize(typed, foldKatakana: isReading)
        guard !given.isEmpty else { return .wrong }
        let candidates = acceptedAnswers(from: back)
            .map { (raw: $0, normalized: normalize($0, foldKatakana: isReading)) }
            .filter { !$0.normalized.isEmpty }
        if candidates.contains(where: { $0.normalized == given }) { return .exact }
        if isReading { return .wrong }
        for candidate in candidates
        where levenshtein(given, candidate.normalized) <= allowedDistance(forLength: candidate.normalized.count) {
            return .nearMiss(expected: candidate.raw)
        }
        return .wrong
    }

    /// NFKC, lowercase, no punctuation or symbols, single spaces. Readings also fold katakana to hiragana.
    public static func normalize(_ s: String, foldKatakana: Bool = false) -> String {
        var out = String.UnicodeScalarView()
        for scalar in s.precomposedStringWithCompatibilityMapping.lowercased().unicodeScalars {
            if CharacterSet.punctuationCharacters.contains(scalar) || CharacterSet.symbols.contains(scalar) {
                continue
            }
            if foldKatakana, (0x30A1...0x30F6).contains(scalar.value), let hiragana = Unicode.Scalar(scalar.value - 0x60) {
                out.append(hiragana)
            } else {
                out.append(scalar)
            }
        }
        return String(out).split(whereSeparator: \.isWhitespace).joined(separator: " ")
    }

    /// The whole back, each part split on , ; / and line breaks, and each of those without (parentheses).
    public static func acceptedAnswers(from back: String) -> [String] {
        let parts = [back] + back.split(whereSeparator: { ",;/\n".contains($0) }).map(String.init)
        var result: [String] = []
        for part in parts {
            for variant in [part, part.replacing(/\([^)]*\)|（[^）]*）/, with: "")] {
                let trimmed = variant.trimmingCharacters(in: .whitespacesAndNewlines)
                if !trimmed.isEmpty, !result.contains(trimmed) { result.append(trimmed) }
            }
        }
        return result
    }

    public static func allowedDistance(forLength n: Int) -> Int {
        switch n {
        case ...3: 0
        case ...5: 1
        case ...7: 2
        default: 2 + (n - 7) / 7
        }
    }

    public static func levenshtein(_ a: String, _ b: String) -> Int {
        let a = Array(a), b = Array(b)
        if a.isEmpty { return b.count }
        if b.isEmpty { return a.count }
        var previous = Array(0...b.count)
        for i in 1...a.count {
            var current = [i] + Array(repeating: 0, count: b.count)
            for j in 1...b.count {
                current[j] = min(previous[j] + 1, current[j - 1] + 1,
                                 previous[j - 1] + (a[i - 1] == b[j - 1] ? 0 : 1))
            }
            previous = current
        }
        return previous[b.count]
    }
}
```

```swift
/// Converts romaji to hiragana as the user types, like WaniKani's reading box.
/// Anything that isn't romaji (kana from a Japanese IME, spaces) passes through unchanged,
/// so the whole field can be re-converted after every keystroke.
public enum RomajiConverter {
    /// - Parameter final: true when submitting: a trailing `n` or `nn` becomes ん.
    ///   While typing, a trailing `n`/`nn` stays Latin because it may still become な, に, にゃ….
    public static func convert(_ input: String, final: Bool = false) -> String {
        let chars = Array(input.lowercased())
        var out = ""
        var i = 0
        while i < chars.count {
            let c = chars[i]
            let next: Character? = i + 1 < chars.count ? chars[i + 1] : nil
            if c == "n" {
                guard let next else {
                    out += final ? "ん" : "n"
                    i += 1
                    continue
                }
                if next == "'" {
                    out += "ん"
                    i += 2
                    continue
                }
                if next == "n" {
                    guard i + 2 < chars.count else {
                        out += final ? "ん" : "nn"
                        i += 2
                        continue
                    }
                    let after = chars[i + 2]
                    // "nni" → ん + に (keep the second n); "nnk" → ん + k.
                    out += "ん"
                    i += isVowel(after) || after == "y" ? 1 : 2
                    continue
                }
                if !isVowel(next) && next != "y" {
                    out += "ん"
                    i += 1
                    continue
                }
            }
            if let (kana, length) = longestMatch(chars, from: i) {
                out += kana
                i += length
                continue
            }
            if isLatin(c), !isVowel(c), next == c {
                out += "っ"
                i += 1
                continue
            }
            out.append(c)
            i += 1
        }
        return out
    }

    public static func containsLatin(_ s: String) -> Bool {
        s.contains(where: isLatin)
    }

    private static func isVowel(_ c: Character) -> Bool { "aeiou".contains(c) }
    private static func isLatin(_ c: Character) -> Bool { c.isASCII && c.isLetter }

    private static func longestMatch(_ chars: [Character], from i: Int) -> (String, Int)? {
        for length in stride(from: min(4, chars.count - i), through: 1, by: -1) {
            if let kana = table[String(chars[i..<i + length])] { return (kana, length) }
        }
        return nil
    }

    private static let table: [String: String] = {
        let vowels = ["a", "i", "u", "e", "o"]
        var t: [String: String] = ["-": "ー", "ya": "や", "yu": "ゆ", "yo": "よ", "wa": "わ", "wo": "を"]
        for (v, k) in zip(vowels, "あいうえお") { t[v] = String(k) }
        let rows: [(String, String)] = [
            ("k", "かきくけこ"), ("s", "さしすせそ"), ("t", "たちつてと"), ("n", "なにぬねの"), ("h", "はひふへほ"),
            ("m", "まみむめも"), ("r", "らりるれろ"), ("g", "がぎぐげご"), ("z", "ざじずぜぞ"), ("d", "だぢづでど"),
            ("b", "ばびぶべぼ"), ("p", "ぱぴぷぺぽ"),
        ]
        for (consonant, kana) in rows {
            for (v, k) in zip(vowels, kana) { t[consonant + v] = String(k) }
        }
        for (romaji, kana) in [("shi", "し"), ("chi", "ち"), ("tsu", "つ"), ("fu", "ふ"), ("ji", "じ")] {
            t[romaji] = kana
        }
        let palatal: [(String, String)] = [
            ("ky", "き"), ("gy", "ぎ"), ("sh", "し"), ("sy", "し"), ("j", "じ"), ("jy", "じ"), ("zy", "じ"),
            ("ch", "ち"), ("cy", "ち"), ("ty", "ち"), ("dy", "ぢ"), ("ny", "に"), ("hy", "ひ"), ("by", "び"),
            ("py", "ぴ"), ("my", "み"), ("ry", "り"),
        ]
        for (prefix, base) in palatal {
            t[prefix + "a"] = base + "ゃ"
            t[prefix + "u"] = base + "ゅ"
            t[prefix + "o"] = base + "ょ"
        }
        t["she"] = "しぇ"; t["je"] = "じぇ"; t["che"] = "ちぇ"
        t["fa"] = "ふぁ"; t["fi"] = "ふぃ"; t["fe"] = "ふぇ"; t["fo"] = "ふぉ"
        for (v, k) in zip(vowels, "ぁぃぅぇぉ") {
            t["x" + v] = String(k)
            t["l" + v] = String(k)
        }
        for prefix in ["x", "l"] {
            t[prefix + "ya"] = "ゃ"; t[prefix + "yu"] = "ゅ"; t[prefix + "yo"] = "ょ"
            t[prefix + "tsu"] = "っ"; t[prefix + "tu"] = "っ"
        }
        return t
    }()
}
```

```swift
/// What the dashboard shows for a deck, and the cards a session would review.
public struct DeckSnapshot: Sendable, Equatable {
    /// Due cards, then today's new cards in Anki's new-card order. Not shuffled.
    public let cards: [ReviewCard]
    /// Due or new-today cards left out because they can't be type-checked.
    public let skipped: Int
    /// Every unsuspended card in the deck, by stage.
    public let stageCounts: [Stage: Int]

    public init(cards: [ReviewCard], skipped: Int, stageCounts: [Stage: Int]) {
        self.cards = cards
        self.skipped = skipped
        self.stageCounts = stageCounts
    }
}

public struct QueueBuilder: Sendable {
    let anki: any AnkiService

    public init(anki: any AnkiService) {
        self.anki = anki
    }

    public func snapshot(deck: String) async throws -> DeckSnapshot {
        let d = "deck:\"\(deck.replacingOccurrences(of: "\"", with: "\\\""))\""

        let infos = try await anki.cardsInfo(try await anki.findCards("\(d) -is:suspended"))
        let byId = Dictionary(infos.map { ($0.cardId, $0) }, uniquingKeysWith: { first, _ in first })

        let due = try await anki.findCards("\(d) is:due -is:suspended -is:buried").compactMap { byId[$0] }
        let perDay = try await anki.newCardsPerDay(deck: deck)
        let introducedToday = try await anki.findCards("\(d) introduced:1").count
        let newToday = try await anki.findCards("\(d) is:new -is:suspended -is:buried")
            .compactMap { byId[$0] }
            .sorted { $0.due < $1.due }
            .prefix(max(0, perDay - introducedToday))

        let selected = due + newToday
        let cards = selected.compactMap(CardContent.reviewCard(from:))
        var stageCounts: [Stage: Int] = [:]
        for info in infos { stageCounts[Stage(interval: info.interval), default: 0] += 1 }
        return DeckSnapshot(cards: cards, skipped: selected.count - cards.count, stageCounts: stageCounts)
    }
}
```

```swift
import Foundation
import Observation

public struct StageChange: Sendable, Equatable {
    public let from: Stage
    public let to: Stage

    public init(from: Stage, to: Stage) {
        self.from = from
        self.to = to
    }
}

/// One review session: the queue, the current card's state, and answers sent to Anki.
@MainActor
@Observable
public final class ReviewSession {
    public enum Phase: Equatable {
        case answering
        case answered(Verdict)
        case finished
    }

    /// Remaining cards; the first one is on screen.
    public private(set) var queue: [ReviewCard]
    public private(set) var phase: Phase
    public private(set) var stageChange: StageChange?
    public private(set) var sendError: String?
    public private(set) var isWrappingUp = false
    public private(set) var completedCount = 0
    public private(set) var correctAnswers = 0
    public private(set) var wrongAnswers = 0
    public private(set) var correctPrompts: [String] = []
    public private(set) var missedPrompts: [String] = []

    private let anki: any AnkiService
    private let requeueOffset: () -> Int
    @ObservationIgnored private var missedIds: Set<Int> = []
    @ObservationIgnored private var stages: [Int: Stage]
    @ObservationIgnored private var pendingSend: (cardId: Int, ease: Int)?

    public init(cards: [ReviewCard], anki: any AnkiService,
                requeueOffset: @escaping () -> Int = { Int.random(in: 3...6) }) {
        self.queue = cards
        self.phase = cards.isEmpty ? .finished : .answering
        self.anki = anki
        self.requeueOffset = requeueOffset
        self.stages = Dictionary(cards.map { ($0.id, $0.stage) }, uniquingKeysWith: { first, _ in first })
    }

    public var current: ReviewCard? { queue.first }

    /// Cards finished plus distinct cards still queued.
    public var total: Int { completedCount + Set(queue.map(\.id)).count }

    public var percentCorrect: Int {
        let answered = correctAnswers + wrongAnswers
        return answered == 0 ? 100 : Int((Double(correctAnswers) / Double(answered) * 100).rounded())
    }

    /// Checks the answer, shows the verdict, and sends it to Anki. Empty answers are ignored.
    public func submit(_ typed: String) async {
        guard phase == .answering, let card = current,
              !typed.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty else { return }
        let verdict = AnswerChecker.check(typed, against: card.answer, kind: card.kind)
        phase = .answered(verdict)
        if verdict.isCorrect {
            correctAnswers += 1
        } else {
            wrongAnswers += 1
            if missedIds.insert(card.id).inserted { missedPrompts.append(card.prompt) }
        }
        pendingSend = (card.id, verdict.isCorrect ? 3 : 1)
        await send()
    }

    public func retrySend() async {
        await send()
    }

    /// Moves to the next card. Does nothing until the current answer has reached Anki.
    public func advance() {
        guard case .answered(let verdict) = phase, sendError == nil, pendingSend == nil, !queue.isEmpty else { return }
        let card = queue.removeFirst()
        if verdict.isCorrect {
            completedCount += 1
            if !missedIds.contains(card.id) { correctPrompts.append(card.prompt) }
        } else {
            queue.insert(card, at: min(requeueOffset(), queue.count))
        }
        if isWrappingUp { queue.removeAll { !missedIds.contains($0.id) } }
        stageChange = nil
        phase = queue.isEmpty ? .finished : .answering
    }

    /// Stops pulling new cards: keeps the card on screen and cards already missed.
    public func wrapUp() {
        isWrappingUp = true
        guard let first = queue.first else { return }
        queue = [first] + queue.dropFirst().filter { missedIds.contains($0.id) }
    }

    private func send() async {
        guard let pending = pendingSend else { return }
        do {
            try await anki.answerCard(pending.cardId, ease: pending.ease)
            pendingSend = nil
            sendError = nil
        } catch {
            sendError = Self.message(for: error)
            return
        }
        // Only for the badge; failing to read the new interval shouldn't interrupt the session.
        guard let info = try? await anki.cardsInfo([pending.cardId]).first else { return }
        let newStage = Stage(interval: info.interval)
        if let oldStage = stages[pending.cardId], oldStage != newStage,
           current?.id == pending.cardId, case .answered = phase {
            stageChange = StageChange(from: oldStage, to: newStage)
        }
        stages[pending.cardId] = newStage
    }

    static func message(for error: Error) -> String {
        switch error as? AnkiError {
        case .notRunning?: "Couldn't reach Anki to save this answer. Make sure Anki is open."
        case .api(let message)?: "Anki couldn't save this answer: \(message)"
        default: "Couldn't save this answer to Anki."
        }
    }
}
```

```swift
@MainActor
enum AnkiLauncher {
    static let bundleID = "net.ankiweb.anki"

    /// Opens Anki in the background and waits for AnkiConnect to answer. False after ~20 s.
    static func openAndWait(anki: any AnkiService) async -> Bool {
        guard let url = NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID) else { return false }
        let configuration = NSWorkspace.OpenConfiguration()
        configuration.activates = false
        _ = try? await NSWorkspace.shared.openApplication(at: url, configuration: configuration)
        for _ in 0..<20 {
            if (try? await anki.deckNames()) != nil { return true }
            try? await Task.sleep(for: .seconds(1))
        }
        return false
    }
}
```

```swift
                answerArea(card)
            }
            Spacer(minLength: 0)
        }

                .keyboardShortcut(.cancelAction)
            Spacer()
            Label("\(session.percentCorrect)%", systemImage: "hand.thumbsup")
            Label("\(session.completedCount) / \(session.total)", systemImage: "checkmark.circle")
            Button(session.isWrappingUp ? "Wrapping up…" : "Wrap up") { session.wrapUp() }
                .disabled(session.isWrappingUp)

            TextField(card.kind == .reading ? "答え" : "Your Response", text: $text)
                .textFieldStyle(.plain)
                .font(.system(size: 28))
                .multilineTextAlignment(.center)
                .foregroundStyle(fieldTextColor)
                .padding(.vertical, 14)
                .background(fieldColor)
                .focused($fieldFocused)
                .modifier(Shake(animatableData: shakes))
                .onSubmit { onReturn(card) }
                .onChange(of: text) { _, newValue in onEdit(newValue, card) }

            feedback(card)
                .padding(.horizontal, 32)
        }
    }

    @ViewBuilder
    private func feedback(_ card: ReviewCard) -> some View {
        if case .answered(let verdict) = session.phase {
            VStack(spacing: 10) {
                switch verdict {
                case .exact:
                    EmptyView()
                case .nearMiss(let expected):
                    Text("Close enough. Expected “\(expected)”").foregroundStyle(.secondary)
                case .wrong:
                    Text("Answer").font(.caption).foregroundStyle(.secondary)
                    Text(card.answer).font(.title2).multilineTextAlignment(.center)
                }
                if !card.notes.isEmpty {
                    Text(card.notes).font(.callout).foregroundStyle(.secondary).multilineTextAlignment(.center)
                }
                if let change = session.stageChange {
                    Text("\(change.to > change.from ? "↑" : "↓") \(change.to.name)")
                        .font(.headline)
                        .foregroundStyle(.white)
                        .padding(.horizontal, 14)
                        .padding(.vertical, 6)
                        .background(change.to.color, in: Capsule())
                }
            }
        }
        if let error = session.sendError {
            HStack {
                Image(systemName: "exclamationmark.triangle.fill").foregroundStyle(.orange)
                Text(error)
                Button("Retry") { Task { await session.retrySend() } }
            }
            .padding(10)
            .background(.orange.opacity(0.15), in: RoundedRectangle(cornerRadius: 8))
        }
    }

    private var fieldColor: Color {
        guard case .answered(let verdict) = session.phase else { return Color(nsColor: .textBackgroundColor) }
        return verdict.isCorrect ? Theme.correct : Theme.wrong
    }

    private var fieldTextColor: Color {
        if case .answered = session.phase { return .white }
        return .primary
    }

    private func onEdit(_ newValue: String, _ card: ReviewCard) {
        if case .answered = session.phase {
            if newValue != submitted { text = submitted }
            return
        }
        if card.kind == .reading {
            let converted = RomajiConverter.convert(newValue)
            if converted != newValue { text = converted }
        }
    }

    private func onReturn(_ card: ReviewCard) {
        switch session.phase {
        case .answering:
            var answer = text
            if card.kind == .reading {
                answer = RomajiConverter.convert(text, final: true)
                text = answer
                if RomajiConverter.containsLatin(answer) {
                    shake()
                    return

                if case .answered(.nearMiss) = session.phase { shake() }
            }
        case .answered:
            session.advance()
            if session.phase == .answering {
                submitted = ""
                text = ""
            }
            fieldFocused = true
        case .finished:
            break
        }
    }

    private func shake() {
        withAnimation(.linear(duration: 0.4)) { shakes += 1 }
    }
}
```

```swift
// Renders the 1024×1024 app icon PNG: a purple rounded square with 記.
// Usage: swift scripts/make-icon.swift <output.png>
import AppKit

let output = URL(fileURLWithPath: CommandLine.arguments[1])
let size = 1024
let rep = NSBitmapImageRep(bitmapDataPlanes: nil, pixelsWide: size, pixelsHigh: size, bitsPerSample: 8,
                           samplesPerPixel: 4, hasAlpha: true, isPlanar: false, colorSpaceName: .deviceRGB,
                           bytesPerRow: 0, bitsPerPixel: 0)!
NSGraphicsContext.saveGraphicsState()
NSGraphicsContext.current = NSGraphicsContext(bitmapImageRep: rep)
let canvas = NSRect(x: 0, y: 0, width: size, height: size)
NSColor(red: 0.63, green: 0.0, blue: 0.94, alpha: 1).setFill()
NSBezierPath(roundedRect: canvas.insetBy(dx: 100, dy: 100), xRadius: 185, yRadius: 185).fill()
let glyph = NSAttributedString(string: "記", attributes: [
    .font: NSFont.systemFont(ofSize: 500, weight: .bold),
    .foregroundColor: NSColor.white,
])
let glyphSize = glyph.size()
glyph.draw(at: NSPoint(x: (CGFloat(size) - glyphSize.width) / 2, y: (CGFloat(size) - glyphSize.height) / 2))
NSGraphicsContext.restoreGraphicsState()
try rep.representation(using: .png, properties: [:])!.write(to: output)
```

- [ ] **Step 2: Write the build script**

`scripts/build-app.sh`:
```bash
#!/bin/zsh
# Builds build/Recall.app from the Swift package.
set -euo pipefail
cd "$(dirname "$0")/.."

swift build -c release --product Recall
BIN="$(swift build -c release --show-bin-path)/Recall"

if [[ ! -f build/AppIcon.icns ]]; then
  mkdir -p build/AppIcon.iconset
  swift scripts/make-icon.swift build/icon-1024.png
  for s in 16 32 128 256 512; do
    sips -z $s $s build/icon-1024.png --out build/AppIcon.iconset/icon_${s}x${s}.png >/dev/null
    sips -z $((s * 2)) $((s * 2)) build/icon-1024.png --out build/AppIcon.iconset/icon_${s}x${s}@2x.png >/dev/null
  done
  iconutil -c icns build/AppIcon.iconset -o build/AppIcon.icns
fi

APP=build/Recall.app
rm -rf "$APP"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
cp "$BIN" "$APP/Contents/MacOS/Recall"
cp build/AppIcon.icns "$APP/Contents/Resources/AppIcon.icns"
cat > "$APP/Contents/Info.plist" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>CFBundleName</key><string>Recall</string>
  <key>CFBundleDisplayName</key><string>Recall</string>
  <key>CFBundleIdentifier</key><string>io.github.noahjohn1.recall</string>
  <key>CFBundleExecutable</key><string>Recall</string>
  <key>CFBundleIconFile</key><string>AppIcon</string>
  <key>CFBundlePackageType</key><string>APPL</string>
  <key>CFBundleShortVersionString</key><string>1.0</string>
  <key>CFBundleVersion</key><string>1</string>
  <key>LSMinimumSystemVersion</key><string>15.0</string>
  <key>NSHighResolutionCapable</key><true/>
  <key>NSAppTransportSecurity</key>
  <dict><key>NSAllowsLocalNetworking</key><true/></dict>
</dict>
</plist>
PLIST
codesign --force --sign - "$APP"
echo "Built $APP"
```

Then: `chmod +x scripts/build-app.sh`
